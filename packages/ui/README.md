# @dhanflow/ui

Dark fintech design system with glassmorphism cards, liquid-gradient actions, and floating dashboard motion.

## Includes

- Theme tokens with financial data typography
- Animation tokens for motion consistency
- Tailwind preset for dark theme styling
- Components:
  - GlassCard
  - LiquidButton
  - PortfolioWidget
  - AssetAllocationChart
  - ClientCard
  - GoalTracker
  - AIInsightPanel
  - ActivityTimeline
  - MarketTicker
  - NotificationBell

## Usage

- Import styles: `packages/ui/src/theme/globals.css`
- Optional Tailwind preset: `packages/ui/src/theme/tailwind-preset.cjs`
- Import components from `@dhanflow/ui`
